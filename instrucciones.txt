Actúa como un Desarrollador Full-Stack Senior y Diseñador UI/UX especializado en aplicaciones React/Next.js interactivas y lúdicas. Tu tarea es construir desde cero un aplicativo web completo, modular, estéticamente cálido y altamente interactivo, pensado para la organización pedagógica del colectivo comunitario "Escuela Popular El Topo".

El aplicativo debe funcionar de inmediato en local (`npm run dev`), estar preparado para desplegarse en Vercel con cero configuración adicional y soportar sincronización con Google Sheets (con respaldo automático en `localStorage`).

## 1. OBJETIVOS Y PRINCIPIOS DEL SISTEMA

1. **Interactividad Lúdica vs. Rigidez de Excel:** Sustituir la edición manual de hojas de cálculo por una experiencia visual basada en tableros dinámicos, tarjetas arrastrables (drag-and-drop), edición rápida en línea (inline-editing) y retroalimentación inmediata.
2. **Tolerancia y Opcionalidad Total:** Ningún campo es obligatorio. Cualquier fecha, hora, responsable, tema o texto puede dejarse en blanco, modificarse después o reordenarse libremente.
3. **Identidad Visual Comunitaria:** Inspirada en el mural de la "Escuela Popular El Topo" (tonos tierra, mostaza cálido, crema, terracota, toques de verde y el personaje del topo como anfitrión amigable), combinada con el orden y contraste azul de la matriz pedagógica institucional.
4. **Exportación Fiel:** Capacidad de descargar un archivo `.xlsx` idéntico en estructura, combinación de celdas y colores a la matriz histórica de jornadas.
5. **Cuidado Colectivo (Pausa Activa):** Temporizador que a los 30 minutos de sesión continua lanza un recordatorio amigable para pausar, estirarse e hidratarse.

---

## 2. STACK TECNOLÓGICO Y PAQUETES RECOMENDADOS

- **Framework:** Next.js (App Router) o React 18+ con Vite y TypeScript.
- **Estilos:** Tailwind CSS con `@tailwindcss/forms` y animaciones suaves.
- **Componentes Base e Iconos:** `lucide-react` para iconos limpios y amigables.
- **Drag & Drop:** `@dnd-kit/core` y `@dnd-kit/sortable` (o `framer-motion`) para reordenamiento fluido de bloques y tarjetas.
- **Exportación Excel:** `exceljs` y `file-saver` para dar estilo exacto a las celdas (colores hexadecimales, bordes, alineación y fuentes).
- **Persistencia:** Capa de abstracción `StorageService`:
  - Modo Offline/Local: `localStorage`.
  - Modo Conectado: Google Apps Script Web App (API REST JSON con `doGet` y `doPost`) o Google Sheets API v4.

// CÓDIGO PARA PEGAR EN: Extensiones > Apps Script en Google Sheets
function doGet(e) {
  var ss = SpreadsheetApp.getActiveSpreadsheet();
  var sheetHitos = ss.getSheetByName("Hitos") || ss.getSheets()[0];
  var sheetJornadas = ss.getSheetByName("Jornadas");

  var dataHitos = sheetHitos.getDataRange().getValues();
  var dataJornadas = sheetJornadas ? sheetJornadas.getDataRange().getValues() : [];

  return ContentService.createTextOutput(JSON.stringify({
    status: "success",
    hitos: dataHitos,
    jornadas: dataJornadas
  })).setMimeType(ContentService.MimeType.JSON);
}

function doPost(e) {
  try {
    var contents = JSON.parse(e.postData.contents);
    var ss = SpreadsheetApp.getActiveSpreadsheet();

    // Guardar Hitos
    if (contents.hitos) {
      var sheetHitos = ss.getSheetByName("Hitos");
      if (!sheetHitos) sheetHitos = ss.insertSheet("Hitos");
      sheetHitos.clear();
      sheetHitos.getRange(1, 1, contents.hitos.length, contents.hitos[0].length).setValues(contents.hitos);
    }

    // Guardar Jornadas
    if (contents.jornadasJson) {
      var sheetMeta = ss.getSheetByName("Jornadas_Data");
      if (!sheetMeta) sheetMeta = ss.insertSheet("Jornadas_Data");
      sheetMeta.clear();
      sheetMeta.getRange(1, 1).setValue(contents.jornadasJson);
    }

    return ContentService.createTextOutput(JSON.stringify({ status: "saved" }))
      .setMimeType(ContentService.MimeType.JSON);
  } catch (err) {
    return ContentService.createTextOutput(JSON.stringify({ status: "error", message: err.toString() }))
      .setMimeType(ContentService.MimeType.JSON);
  }
}
